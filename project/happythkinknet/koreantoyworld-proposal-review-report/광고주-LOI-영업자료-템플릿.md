# 광고주 LOI · 영업 자료 템플릿 (Founding Advertiser Program)

> **작성** 2026-06-22 · K-Toy 그로스 디렉터 | **연결** `90일-실행안.md` WS1 (CSF-1 공급측 수요 검증)
> **용도:** 90일 검증 스프린트에서 제조사·브랜드로부터 **서면 LOI 5~10건**과 그들의 **요구 KPI·지불의향 단가**를 확보하기 위한 영업 키트.
> **설계 원칙(보고서 정합):** ① 검증 안 된 트래픽을 과장하지 않는다 ② **노출보장 + 미달 시 크레딧 보상**으로 광고주 리스크를 0으로 만든다 ③ LOI 자체가 단가·KPI 데이터 수집 도구다 ④ "왜 굳이 여기에"의 답 = **자기 커머스 연계 closed-loop 성과 증명**.

## Part A. 영업 접근 전략 (How to Use)

### A-1. 핵심 프레이밍 — "Founding Advertiser(창립 광고주) 프로그램"
신규 매체이므로 "이미 트래픽이 많다"가 아니라 **"15년 KoreanToyShop 자산 위에 K-Toy 미디어를 런칭하며, 초기 파트너에게 창립 광고주 특권을 준다"**로 접근한다. 정직하면서도 매력적인 구조:
- **창립 광고주 할인**(정가 대비 30~50%) + 가격 동결.
- **노출 보장 + 미달 시 크레딧 보상** → 광고주는 트래픽 리스크를 지지 않는다.
- **성과 리포팅**(노출·클릭·KoreanToyShop 전환 기여) 제공 → ROI를 눈으로 본다.
- 파일럿이므로 **단기·소액**으로 시작 가능 → 진입장벽 최소화.

### A-2. 타깃 세그먼트 (우선순위)
1. **이미 KoreanToyShop과 거래 중인 제조사/브랜드** — 관계·신뢰 존재, 1순위(단, '을→갑' 관계 전환임을 인지).
2. **글로벌 진출 의향이 있는 중소 K-캐릭터/완구 브랜드** — 자체 해외 마케팅 역량 부족, 미디어 노출 니즈 큼.
3. **신제품·시즌 런칭이 잦은 브랜드** — New Season/Global Launch 상품 적합.

### A-3. 90일 영업 퍼널 목표
| 단계 | 목표 |
|---|---|
| 아웃리치(타깃) | 30곳 |
| 1차 미팅 | 15곳 |
| LOI 서면 | **5~10건** |
| 파일럿 유료 전환 | 1~2건 |

**무엇을 제공하나요?**
귀사의 브랜드·신제품을 **K-Toy를 찾는 글로벌 컬렉터·바이어**에게 콘텐츠와 함께 노출합니다 — New Korean Toys / Character Guide / Brand Page / Top Ranking 등.

**왜 여기에 광고해야 하나요? (다른 채널과 다른 점)**
- ✅ **성과를 증명합니다.** 광고 노출 → KoreanToyShop 실제 구매로 이어진 **기여 매출을 대시보드로 보여드립니다.** (일반 배너 광고가 못 주는 것)
- ✅ **트래픽 리스크 0.** 약속한 노출에 미달하면 **크레딧으로 보상**합니다.
- ✅ **초니치 정밀 도달.** "한국 완구를 찾아온" 고관여 오디언스에만 노출.

**창립 광고주 특권 (선착순 [10]곳)**
- 정가 대비 **[30~50]% 할인** + 1년 가격 동결
- 우선 슬롯 배정 + 성과 리포팅 무료
- 파일럿 단기·소액 시작 가능

**다음 단계**
관심 있으시면 **이용의향서(LOI)** 한 장으로 시작합니다 — 구속력 없이, 원하는 광고 상품·예산·기대 성과만 알려주시면 됩니다.

## Part D. LOI 수집 데이터 → 환류 (Data Capture)

서명된 LOI는 단순 영업 실적이 아니라 **요율표·P&L의 입력값**이다. 매 건 아래를 집계한다:

| 수집 항목 | 환류 대상 |
|---|---|
| 관심 상품 분포 | rate card 상품 우선순위 |
| 평균 지불의향 단가(월) | 매출계획 ARPU 가정 검증 |
| 요구 KPI(노출/클릭/전환) | 노출보장 수준·성과 리포팅 스펙(WS4) |
| 계약 기간 선호 | 정산주기·갱신율 가정 |
| 데이터 구독 관심도 | WS5 데이터 상품 우선순위 |

**90일 Go 판정 직결 지표:** LOI **5건+** & 평균 지불의향 **≥ 월 20만**.

### E-2. 1차 미팅 질문 리스트 (LOI 데이터 확보용)
1. 현재 해외 마케팅은 어떤 채널로, 월 얼마나 쓰시나요? (예산 규모 파악)
2. 가장 풀고 싶은 문제는? (인지 / 바이어 발굴 / 판매 중 무엇?)
3. 광고 성과를 무엇으로 판단하시나요? (요구 KPI)
4. 신제품·시즌 런칭 주기는? (상품 매칭)
5. 월 어느 정도 예산이면 "시도해볼 만하다"고 느끼시나요? (지불의향가)
6. 데이터로 "내 제품이 해외 어디서 검색·판매되는지" 알 수 있다면 유료 구독 의향이 있으신가요? (WS5)

---

> **요약:** 이 키트의 목적은 "광고를 파는 것"이 아니라 **"공급측 수요가 실재하는지 90일 안에 데이터로 확인하는 것"**이다. LOI가 잘 나오면 → 풀빌드 GO의 가장 강한 근거. LOI가 안 나오면 → 가장 값진 NO-GO 신호(3,000만 보호). 모든 항목은 트래픽을 과장하지 않고, **광고주 리스크를 보상으로 제거**해 정직하게 설계했다.
