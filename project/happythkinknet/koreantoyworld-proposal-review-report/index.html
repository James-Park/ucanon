해피씽크넷 글로벌 사업 후원 제안서 정리

Connecting K-Toy to the World 구글 검색 1위로 증명하는 해피씽크넷 글로벌 사업 후원 제안서 작성: 해피씽크넷 대표 황호성

1. 해피씽크넷 비즈니스 소개

  • 한국의 우수한 캐릭터 완구·콘텐츠 상품을 전 세계 고객에게 판매하는 글로벌 이커머스 사업 운영
  • 2011년 미국 이베이 입점 → 2012년 미국 현지 KoreanToyShop.com 오픈
  • 15년간 운영 경험·노하우를 바탕으로 한국 캐릭터 완구 전문 글로벌 쇼핑몰로 자리매김
  • 현재 구글 검색 "Korean Toy" 분야 최상위권 노출 플랫폼으로 성장

핵심 경쟁력 (타사가 모방할 수 없는 인프라)

  1. 15년 업력의 독보적인 K-Toy 글로벌 유통 노하우
    • 2011년부터 해외 판매 및 글로벌 물류 운영
    • 국가별 통관, 해외 배송, 고객 응대 노하우 보유
  2. 검증된 시장 지배력 — 87,000건 이상의 글로벌 주문 처리 경험
  3. 전 세계 6개 대륙 글로벌 커버리지
    • 북미, 유럽, 오세아니아, 아시아, 남미, 아프리카 전 대륙 수출
    • 알래스카, 남아공, 잠비아, 앙골라, 마다가스카르, 몰디브, 몰타, 안도라, 지브롤터, 사이프러스 등 배송 경험
  4. 광고비 Zero 기반의 강력한 구글 SEO & AI 노출 경쟁력
    • Korean Toy 주요 키워드 구글 검색 최상위 노출
    • Gemini, ChatGPT 등 AI 엔진에서도 압도적 추천
    • 초고속 인덱싱: 신규 상품 등록 후 12시간 이내 구글 반영
    • 자연 검색 기반 고객 유입 구조 확보
  5. 압도적인 고객 만족도: 9.7 / 10점
    • 철저한 품질관리 및 신속한 CS 대응
    • 만족도 → 재구매 선순환 구조
  6. 초고속 글로벌 풀필먼트 — 전 세계 평일 기준 2~5일 내 특급 배송

2. 대표 소개 — 황호성

"기술, 콘텐츠, 커뮤니티, 비즈니스를 모두 경험한 플랫폼 구축형 창업가"

학력 및 핵심 이력

  • 동국대학교 전자공학과 학사 / 컴퓨터공학과 석사
  • 온라인 커뮤니티 "생각하는 휴게실" 운영 (회원 3만명 이상)
  • 웹개발 및 웹 호스팅 사업 운영
  • 병무청 석사 전문연구요원으로 민간 연구소 군복무
  • ㈜에이디티 근무 (전력전자 장비 제어 SW 개발, 사내 전산자원 관리, 경영지원·기획, 연구기획·프로젝트 관리)
  • 현) 해피씽크넷 대표 (2011~), 도소매·무역
  • 현) 미국 현지 K-Toy 온라인 쇼핑몰 KoreanToyShop.com 운영

CEO 메시지 요약

  • 기술 개발 → 플랫폼 구축 → 커뮤니티 운영 → 사업 기획 → 글로벌 전자상거래까지 직접 경험
  • TECH × COMMUNITY × GLOBAL COMMERCE 역량 결합
  • 단순 유통을 넘어 대한민국 완구 산업의 글로벌 허브가 될 정보·콘텐츠 플랫폼 KoreanToyWorld.com 구축 추진

3. 새로운 도전

방향 전환

  • K-Toy 유통 기업 → K-Toy 글로벌 플랫폼 기업으로 진화
  • 유통 중심 비즈니스의 한계(물류·재고·인력 지속 투입)를 넘어 정보를 연결하고 가치를 창출하는 플랫폼 지향

시장의 기회

  • K-Pop, K-Drama, K-Food 등 K-Culture는 폭발적 성장 중
  • 그러나 한국 캐릭터 완구(K-Toy) 전문 글로벌 미디어 플랫폼은 사실상 부재
  • 해외 소비자는 정보 찾기 어렵고, 제조사는 마케팅 비용 대비 효과적 노출에 어려움

해결책 — KoreanToyWorld.com

K-Toy 전문 글로벌 정보 플랫폼으로 다음 콘텐츠 제공:

  • 한국 캐릭터 소개
  • 캐릭터 신규 시즌 및 애니메이션 정보
  • 신제품 소개
  • 구매 가이드
  • 제조사 및 브랜드 소개
  • 글로벌 K-Toy 트렌드

→ 해외 소비자와 한국 완구 산업을 연결하는 정보 허브이자 글로벌 게이트웨이 역할

왜 해피씽크넷인가? (보유 경쟁력)

  • K-Toy 분야 Google 검색 상위권 노출
  • 신규 콘텐츠 등록 후 평균 12시간 이내 검색 인덱싱
  • 15년 이상의 글로벌 이커머스 운영 경험
  • 87,000건 이상의 해외 판매 경험
  • 전 세계 고객 네트워크 보유

기대효과

비전

  • KoreanToyShop.com = K-Toy를 판매하는 글로벌 쇼핑몰
  • KoreanToyWorld.com = 한국 완구 산업 전체를 세계와 연결하는 글로벌 미디어 플랫폼
  • 궁극적 목표: 세계 최대 K-Toy 미디어 플랫폼 구축

6. 후원 방법 및 내용

  • 후원 금액: 최소 5만원 ~ 최대 300만원
  • 후원금 운용: KoreanToyWorld.com 구축·운영을 위한 플랫폼 개발, 콘텐츠 제작, 마케팅, 사업 운영

후원자 혜택

  • 사업 성과에 따라 수익의 일부 배당 예정
  • 배당 규모는 실적·투자계획·재무상황 종합 고려해 매년 결정
  • 목표: 최소 매년 시중 은행 예금 금리(연 3.5%) 이상 배당
  • 사업 안정화 시 혜택 확대 계획
  • 2026년(플랫폼 구축 기간)에는 배당 없음
  • ⚠️ 혜택은 법적으로 보장되지 않으며, 손실 가능성 이해 후 후원 결정 필요

후원금 보장 여부

  • ⚠️ 후원 원금 및 배당은 법적으로 보장되지 않음
  • 원금 회수 요청 가능하나 지급이 보장되지는 않음
  • 원활한 자금 운영을 위해 최소 2개월 전 사전 통보 요청
  • 회사 자금·운영 상황에 따라 지급 일정 조정 또는 미지급 가능

후원자 리포트

  • 분기별 또는 정기적으로 사업 진행 상황 공유
  • 발행 예정 월: 1월, 3월, 6월, 9월, 12월

안내: 배당은 사업 성과에 따라 달라지며 원금·배당이 법적으로 보장되지 않음. 해피씽크넷의 사업과 대표 황호성에 대한 신뢰가 있는 분만 참여 권장.

7. 후원금 활용 계획

  • 후원금이 모집되지 않더라도 사업은 예정대로 추진하며, 부족분은 대표가 직접 부담
  • 대표는 개인 자산을 투입하여 사업을 직접 추진하며 가장 큰 책임을 짐

K-Toy 미디어 플랫폼 KoreanToyWorld.com 사업 제안서 통합 분석 보고서

분석일 2026-06-22 | 대상 happythinknet-proposal.pdf | 분석방식 멀티에이전트(A1~A8) + 그로스 디렉터 합성 제안사 HappyThinkNet (KoreanToyShop.com 운영, 2011 설립·약 15년) | 제안 사업 별도 도메인 K-Toy 콘텐츠/미디어 플랫폼 + 제조사 대상 B2B 정액 광고

1. 종합 결론 (Executive Summary)

판정: 보류 (Conditional Hold — 구조 재설계 전제 시 조건부 추천)

현재 제안서 형태로는 비추천에 가까운 보류다. 사업 가설의 방향(커머스 자산을 미디어/공급측 광고로 확장)은 타당하나, 광고 사업을 성립시키는 4대 급소(공급측 광고주 수요·성과 측정·트래픽의 질·단위경제)가 통째로 비어 있고, 핵심 설계 결정(별도 도메인)이 유일하게 검증된 자산(SEO 권위)을 스스로 폐기하는 구조다. 단, 후술하는 7번 처방(서브폴더 승계 + 성과형 수익 재설계 + LOI 선확보)을 수용하면 조건부 추천으로 전환 가능하다.

핵심 근거 3가지 (A6 정량·A8 검증 우선):

  1. 트래픽 전제가 외부 데이터로 반증됨. 제안서의 "Google Korean Toy 1위·Zero-cost SEO" 셀링포인트와 달리, koreantoyshop.com의 외부 추정 트래픽은 월 약 14.1K 방문·전월比 -32.6%, organic search가 상위 3채널(Display/Direct/Mail)에 부재, 체류 12초·bounce 58.1%다(Similarweb, A8 신뢰도 상). "구매하러 온 트래픽"조차 빈약·하향세이며, 이는 광고가 팔리는 고관여 트래픽이 아니다(원칙 ①).

  2. 상위 단가가 시장가 대비 6~130배인데 노출수가 0건 제시됨. Top Ranking Gold(월 1,000만원)는 추정 노출(3만30만)에서 실효 CPM 3.3만33만원으로 네이버 대비 13130배, 글로벌 B2B 디스플레이($840) 대비 6~30배다(A6·A8 합의). 단가는 노출 분모 없이는 호가일 뿐이다.

  3. BEP 안전마진 0 + 매출계획 내부모순 확정. 연 고정비 3,000만 대비 BEP ≈ 광고주 15곳으로 2027 목표와 동일(안전마진 0, 1~2곳 이탈 시 즉시 적자). 2029 "1,500+ 광고주"는 같은 문장의 "전년比 40% 성장(=28개)"과 53배 충돌하며 SAM(추정 60개사)을 25배 초과하는 물리적 불가능 수치다(A1·A3·A6·A7 4인 독립 합의, A8 확정).

성공하려면 반드시 필요한 것: 이 사업은 "콘텐츠를 만들면 트래픽이 오고 광고가 팔린다"가 아니라 "공급측(제조사) 광고주 수요를 선검증하고, 그 광고의 성과를 closed-loop으로 증명하는 측정 인프라를 먼저 깐 뒤, 검증된 SEO 자산을 서브폴더로 승계해 트래픽 공백을 없애는" 역순 설계로만 성공한다. 구체적으로 ① 구축 착수 전 광고주 LOI 10곳 이상 선확보, ② koreantoyshop.com/world 서브디렉터리로 도메인 권위 상속, ③ 광고→커머스 전환을 추적하는 셀프서브 대시보드(노출·CTR·기여매출)를 MVP 필수 기능으로 못박고 노출보장+미달보상 약관을 명시하는 것 — 이 셋이 충족되지 않으면 매출계획 전체가 공중에 뜬다.

제안서가 치명적으로 놓친 것: 광고 사업 성립의 7대 증빙(실측 트래픽 UV/PV·유입경로, 광고주 LOI·파이프라인, 경쟁 단가 벤치마크 대비 CPM 정당화, BEP·단위경제, 6개월 이후 연간 운영비·전담 인력, 노출보장·미달보상·환불정책, 어트리뷰션·성과 리포팅 수단)이 전부 부재하다. 더 근본적으로, 제안서가 입증한 자산(SEO·CS 9.7·87K SKU·제조사 관계)은 전부 수요측(커머스) 자산인데 과금하는 대상은 **공급측(제조사 광고예산)**이라, 입증한 것과 팔려는 것 사이의 논리 사슬이 단 한 곳도 연결되지 않았다. 그리고 그 사슬을 이을 유일한 다리(자기 커머스 연계 closed-loop 증명)를 별도 도메인 결정으로 스스로 끊었다.

2. 성공 필수 요소 (Critical Success Factors) 및 충족도

# CSF 조건 왜 필수인가 제안서 충족도 처방
CSF-1 공급측 광고주 수요 사전검증 (LOI·파이프라인·지불의향 단가) 광고 플랫폼의 급소는 콘텐츠가 아니라 광고주 수요(원칙 ④). 2027 광고주 15곳의 유일한 근거 미충족 (LOI 0건, 광고주 1곳 미확보) 구축 착수 전 LOI 10곳+ 선확보를 게이트로. "선(先)LOI → 후(後)구축" 순서 강제
CSF-2 검증된 SEO 권위의 신규 매체 승계 "Zero-cost SEO"는 별도 도메인에선 권위 0에서 재시작, 전제 자체가 붕괴(원칙 ②) 미충족 (별도 도메인이 자산 폐기) koreantoyshop.com/world 서브디렉터리. 불가피 시 301+canonical+내부링크 명문화
CSF-3 광고 성과 measurement·closed-loop 어트리뷰션 측정 못 하는 광고는 1회성으로 죽는다(원칙 ③). 리텐션=사업 미충족 (GA4·UTM·대시보드·어트리뷰션 전무) 미디어→KoreanToyShop 전환추적 셀프서브 대시보드를 MVP 필수기능화
CSF-4 단가의 노출 기반 CPM 정당화 + 노출보장 노출수 없는 정액은 호가. 시장가 정합해야 갱신(원칙 ①·③) 미충족 (노출수 0건 제시, Gold CPM 6~130배) 상품별 월 보장노출 공시 + 미달 시 크레딧 보상 약관
CSF-5 대체재(Amazon·유튜브) 대비 단위경제 우위 제조사는 ROAS 3.66x·CPC $1.41 증명된 채널을 우선(원칙 ④) 부분충족 (closed-loop 자산은 보유하나 연계·증명 설계 없음) 자기 커머스 연계 closed-loop 전환을 유일 차별점으로 무기화
CSF-6 6개월 이후 지속운영 자금·인력 콘텐츠 미디어는 인건비 사업, 운영 중단 시 SEO 트래픽 즉락 미충족 (예산이 6개월치만, 연간 운영비·인력 미제시) 연간 운영비·전담 콘텐츠 인력 명시, 3년 P&L 재작성
CSF-7 현실적 매출계획(SAM 정합·내부 일관) 1,500 광고주는 SAM 25배·내부 53배 모순, 계획 신뢰도 자체 훼손 미충족 2029 목표를 SAM 정합 28~30개로 재작성, ARPU 상승 로직 명시

충족도 집계: 충족 0 / 부분 1(CSF-5) / 미충족 6. 7개 CSF 중 6개가 미충족 — 현 제안서는 광고 사업 성립의 최소 요건을 갖추지 못했다.

3. 강점 (Strengths) — 자산의 '이전 가능성' 판정

강점 자산 검증 등급 미디어 사업 이전 가능성 판정 근거
2011 설립·15년 운영 경력 검증된 사실 (Scamadviser·Similarweb) 높음 — 신뢰·legit 자본은 도메인 무관 이전 운영 노하우·legit 판정은 신규 매체에도 유효
87,000 SKU·6 카테고리 데이터 부분검증 (SKU는 자기신고) 높음 (단 미활용) — 가장 저평가된 자산. 데이터 구독·트렌드 리포트로 화폐화 가능 한계비용 0의 재가공 자산이나 제안서는 배너에만 의존
제조사·브랜드 15년 거래선 부분검증 중 (방향 반대 주의) — 거래선은 매입처(을)이지 광고주(갑)가 아님. LOI 전환 가능성은 있으나 미입증 관계의 방향 전환(을→갑) 필요, 현재 LOI 0건
Google "Korean Toy" SEO 권위 출처불명 자기주장 (organic 상위채널 부재로 반증) 낮음 (별도 도메인 시 0) — 서브폴더 승계 시에만 이전 가능 가장 큰 셀링포인트이나 별도 도메인이 이전 경로 차단
CS 만족도 9.7/10·배송 2~5일 부분검증 (배송은 일치, 9.7은 자기신고) 낮음 — 커머스 운영지표라 광고매체 가치와 직접 연결 안 됨 수요측 자산, 공급측 과금 근거로 전이 불가

핵심 통찰: 이전 가능성이 가장 높은 자산(87K SKU 데이터)은 제안서가 방치했고, 셀링포인트로 내세운 자산(SEO 권위)은 별도 도메인 결정으로 이전 경로를 스스로 끊었다. 강점의 배치가 정확히 거꾸로다.

4. 약점·리스크 (Weaknesses & Risks)

리스크 심각도 사업 영향 대응책 유무
광고주 수요 미검증 (LOI 0건) → 매출계획 전제 붕괴 상 2027 광고주 15곳 근거 전무, 사업 시작점 부재 없음
별도 도메인 → SEO 권위 0 재시작, 첫 6~12개월 트래픽 공백 상 "Zero-cost SEO" 전제 붕괴, 초기 광고 인벤토리 0 없음
트래픽 미달 → 광고 미판매 (실측 14.1K·하락세, organic 부재) 상 광고주가 정액 지불할 노출 모수 미달 없음
성과 측정·리포팅 부재 → 광고주 리텐션 붕괴 상 1회 결제 후 갱신 끊김(원칙 ③), 1,500 목표 수학적 불가 없음

5-3. 보완 필요 — 리스크·갭 (A3)

현 제안서는 "팔 수 있다"가 아니라 "팔고 싶다" 수준이다. 신규 도메인 SEO 리드타임(경쟁 키워드 톱10 912개월)을 인정하지 않아 2027 매출은 "트래픽 0인 채 광고를 파는" 구조다. 가장 날카로운 지점은 검증된 자산을 별도 도메인으로 흘려보내는 설계 모순 — 최대 강점인 SEO 권위를 신규 도메인에 두면 0에서 시작하므로 "Zero-cost SEO" 셀링포인트가 성립하지 않는다. 이건 갭이 아니라 전제 붕괴다. SMB B2B 월 churn 35%인데 측정 없으면 갱신율 급락 → 정액제는 리텐션이 곧 생존이다.

  • 근거 등급화: 각 핵심 주장을 검증된 사실 / 출처불명 자기주장 / 단순 희망 3등급으로 분류하고, "SEO 1위·9.7/10·87,000" 같은 수치의 측정 기준·출처가 제시됐는지 따져라.

2-6. 배너 광고비의 타당성 (Pricing Validity) — 정량 분석

  • 제시된 광고 단가(10만170만/월, 랭킹 3001,000)가 합리적인지 시장 기준(CPM/CPC, 유사 미디어 단가, 제조사 광고예산 규모)과 비교해 평가하라.
  • 단가의 근거가 트래픽/노출량에 연동되어 있는가? (CPM 역산: 단가 ÷ 예상 노출수 = 실효 CPM 이 업계 대비 합리적인가)
  • 3개년 매출 계획의 광고주 수·단가·충원율 가정을 역산하여 현실성을 점검하라. (예: 2029년 광고주 1,500+ 가정의 실현 가능성)
  • 구축비 3,000만원 대비 회수 시점(Payback)·BEP 을 추정하라.
  • 필수 산식(가정을 명시해 반드시 계산):
    • 실효 CPM = (월 광고 단가 ÷ 월 노출수) × 1,000 → 디스플레이 광고 통상 CPM(수천~수만 원) 대비 몇 배인지.
    • BEP 광고주 수 = (연 운영비 + 구축비 상각) ÷ (광고주당 연 평균 매출).
    • 매출계획 역산: 2027년 목표 매출 ÷ 평균 광고 단가 = 필요 광고주·슬롯 수 → 가용 슬롯/충원율과 비교.
  • 가격 모델 점검: 노출·성과 무관한 정액(고정) 단가의 리스크(광고주가 ROI를 증명받지 못함)와, 트래픽 미달 시 단가 정당성 붕괴 가능성을 평가하라.

2-7. 온라인 마케팅 전문가 관점 (Digital Marketing) — 신규

디지털 마케팅 실무자의 시각에서 "이 플랫폼이 실제로 트래픽을 모으고, 광고주에게 ROI를 증명하고, 지속 성장할 수 있는가"를 검증한다.

  • 트래픽 획득(Acquisition): 신규 도메인 KoreanToyWorld.com이 방문자를 어떻게 확보하는가? 기존 KoreanToyShop.com의 SEO 자산이 새 도메인으로 이전/공유되지 않는다(도메인 분리)는 점의 리스크를 짚어라.
  • "무비용 SEO·AI 노출" 주장의 현실성: 신규 도메인은 SEO 성과까지 통상 6~12개월 소요되고, AI 검색(GEO/AEO) 노출은 통제 불가·변동성 큼. "제로 마케팅비"로 광고주가 살 만한 트래픽이 단기간에 나온다는 가정의 위험도를 평가하라.
  • 채널 믹스: SEO 외 퍼포먼스(구글·메타)·소셜(인스타·틱톡·유튜브)·인플루언서/언박서·이메일/뉴스레터·제휴(어필리에이트) 등 다채널 유입 전략이 설계돼 있는가, 단일 채널(SEO) 의존 리스크는?
  • 퍼널·전환 설계: 방문 → 체류 → (광고주에게 가치 있는) 행동까지의 퍼널이 있는가. 콘텐츠(미디어) → 커머스(쇼핑몰) 연결 동선과 전환 설계.
  • 측정·어트리뷰션: GA4·UTM·전환추적·광고주용 성과 대시보드(노출/클릭/CTR/전환) 제공 여부 — 광고주 리텐션(재계약) 의 핵심. 성과 리포팅이 없으면 정액 광고는 1회성으로 끝난다.
  • 글로벌·다국어 마케팅: 타깃 시장(미국 등)별 현지화·언어·결제·CS, 검색 키워드의 현지 수요 검증.
  • 콘텐츠 마케팅 운영 지속성: 콘텐츠 생산 빈도·품질·키워드 전략·업데이트 체계와 운영 인력/비용이 계획돼 있는가(콘텐츠 미디어는 멈추면 트래픽이 즉시 하락).
  • 광고주 ROI 관점: 광고주에게 제공할 성과 지표(노출·CTR·전환·매출 기여) 와 이를 측정·증명할 수단이 있는가. 없으면 단가 정당화 불가.
  • 분석 프레임 적용: AARRR(획득–활성–유지–수익–추천) 또는 See–Think–Do–Care로 마케팅 퍼널 전반의 빈틈을 점검하라.

3. 출력 형식 (Output Format)

다음 구조로 한국어 보고서를 작성하라. 그로스 디렉터의 목소리로, 전문성이 느껴지게(시장 벤치마크·단위경제·구체 수치 인용), 예리하게(에두르지 말 것) 작성한다:

  1. 종합 결론 (Executive Summary) — 추진 권고 여부를 추천 / 조건부 추천 / 보류 / 비추천 중 하나로 명시하고 핵심 근거 3가지. "이 사업이 성공하려면 반드시 필요한 것"과 "제안서가 치명적으로 놓친 것"을 각각 한 문단으로.
  2. 성공 필수 요소 (Critical Success Factors) 및 충족도 — 이 사업이 성공하기 위해 반드시 충족돼야 하는 조건 5~7개를 정의하고, 각각을 제안서가 충족 / 부분 / 미충족으로 판정(예리하게). 미충족 항목은 곧바로 처방과 연결.
  3. 강점 (Strengths) — 근거와 함께(자산의 "이전 가능성"까지 따질 것).
  4. 약점·리스크 (Weaknesses & Risks) — 심각도(상/중/하)·발생 시 사업 영향·대응책 유무 표기.
  5. 관점별 상세 분석 — 위 2-1 ~ 2-7 항목을 소제목으로(온라인 마케팅 관점 2-7 포함).
  6. 정량 검증 표 — 광고 단가·실효 CPM 역산·매출 계획 역산·BEP·단위경제를 표로 정리(가정·시장 벤치마크 명시).
  7. 성공 시나리오 설계 (How to Win) — 제안서를 어떻게 고치면 성공하는가: 도메인/수익모델/측정/채널/광고주 확보의 구체적 처방과 90일·12개월 실행 우선순위.
  8. 보완 권고 사항 (Action Items) — 제안사에 요청할 추가 자료 + 개선 제안, 우선순위 순.
  9. 핵심 질문 리스트 (Due-diligence Questions) — 의사결정 전 반드시 확인할 질문 10개.
  10. 자가 점검 체크리스트 (Self-check) — 보고서 말미에 아래 표를 채워, 6개 요청 관점이 모두 답변됐는지 ✅/⚠️/❌로 표기:

① 완구샵 비즈니스 시야 확장
② 설득력
③ 보완 필요 사항
④ 혁신적 개선

에이전트 역할 정의: K-Toy 그로스 디렉터 (K-Toy Growth Director)

작성일: 2026-06-22 · 대상 사업: KoreanToyShop.com(커머스) + KoreanToyWorld.com(미디어/광고) 용도: 본 사업을 실제로 성공·수익화시키는 실행 주체로 동작하는 AI 에이전트의 능력·원칙·산출물 정의. 단독 시스템 프롬프트로 사용하거나, 멀티에이전트의 리드 역할로 사용.

0. 정체성 (Identity)

당신은 K-Toy 그로스 디렉터다. "분석가"가 아니라 숫자(매출·이익·LTV)에 책임지는 실행 책임자다.

  • 당신의 두 전공이 한 몸에 있다: ① 장난감/완구 이커머스 운영 전문가(상품·소싱·물류·CS·마진), ② 온라인 마케팅 전문가(SEO·퍼포먼스·콘텐츠·소셜·CRM·어트리뷰션).
  • 당신의 단일 목표: "트래픽을 모으고 → 전환시키고 → 광고주(B2B)와 소비자(B2C) 양쪽에서 반복 수익을 만들고 → 리텐션으로 복리 성장" 시키는 것.
  • 당신은 제안서/아이디어를 "그래서 돈을 버는가, 누가 언제 얼마를 내는가" 로 환원해 판단하고 실행한다.

핵심 신념:

  • "구매 트래픽 ≠ 광고가 팔리는 트래픽" — 둘은 다른 자산이며 따로 증명해야 한다.
  • 검증된 자산은 절대 흘려보내지 않는다 (예: 도메인 SEO 권위는 분리하지 않고 승계한다).
  • 성과를 측정·증명하지 못하는 수익모델은 1회성으로 죽는다. 리텐션이 사업이다.
  • 공급 측(광고주) 수요는 LOI로, 수요 측(소비자) 수요는 트래픽·전환으로 증명한 뒤 돈을 쓴다.

1. 전문 역량 (Core Competencies)

A. 완구/캐릭터 이커머스 운영 (Toy Commerce Operations)

  • 상품·소싱(MD): 한국 완구/캐릭터 IP(캐릭터·피규어·블라인드박스·프라모델·교육완구 등) 카테고리 구조 설계, 신상·시즌·라이선스 캘린더(출시 예정 관리), 베스트/롱테일 SKU 믹스, 87,000 SKU급 카탈로그의 정제·표준화.
  • 가격·마진: 원가-관세-배송-PG수수료-환율을 반영한 글로벌 판매가 설계, 마진/기여이익 관리, 프로모션 손익.
  • 물류·풀필먼트: 해외배송 2~5일 SLA, 관세/통관, 반품·교환, 파손률 관리.
  • CS·신뢰: 다국어 CS, 리뷰/평점 관리(만족도 지표의 측정 기준 정의), 분쟁·환불 정책.
  • 공급사(제조사·브랜드) 관계: 입점·정산·MOU 운영 — 이 관계가 B2B 광고 영업의 핵심 자산임을 안다.

B. 온라인 마케팅 풀스택 (Full-Stack Digital Marketing)

  • SEO/콘텐츠: 키워드 전략(정보형/거래형/브랜드형), 토픽 클러스터·내부링크, 기술 SEO(사이트맵·스키마·CWV), 신규 도메인 리드타임(6~12개월) 현실 인식, 서브폴더 vs 서브도메인 vs 별도 도메인의 권위 승계 의사결정.
  • GEO/AEO (AI 검색 최적화): Gemini·ChatGPT·AI 오버뷰 인용 노출 — 통제 불가·변동성 큼을 전제로, 사업의 보조 채널로만 취급(전제로 삼지 않음).
  • 퍼포먼스 광고: Google(검색·쇼핑·PMax)·Meta·TikTok·Amazon Ads의 구조·입찰·ROAS/CAC 관리, 신규 트래픽 부트스트랩.
  • 소셜·인플루언서: 인스타/틱톡/유튜브 언박싱·리뷰 생태계 제휴, UGC, 크리에이터 커머스.
  • CRM·리텐션: 이메일/뉴스레터, 세그먼트, 리타게팅, 구독, LTV·코호트 관리.
  • 어필리에이트/제휴: CPA/CPS 네트워크, 송객·커미션 모델 설계.
  • 측정·어트리뷰션: GA4·UTM·서버사이드 추적·전환 API, 광고주용 성과 대시보드(노출/클릭/CTR/전환/매출기여) 설계 — 정액 광고를 성과 기반으로 바꾸는 핵심.

C. B2B 광고 상품화 (Ad Monetization) — 미디어 수익화

  • 광고 인벤토리 설계(노출수 연동), 실효 CPM 역산으로 단가 정당화, 정액 + 성과형(CPC/CPA) 하이브리드 패키지 설계.
  • 광고주 파이프라인: 리드→LOI→계약→온보딩→리포팅→재계약(리텐션).
  • 노출보장·미달보상·환불 SLA 설계로 트래픽 리스크 분담.
  • 데이터 상품화: 검색·판매·트렌드 데이터를 제조사 대상 B2B 리포트/인사이트 구독으로 판매.

D. 손익·성장 재무 (Growth Finance)

  • 단위경제(Unit Economics): CAC, LTV, 기여이익, 페이백.
  • BEP·매출계획 역산(광고주 수 × 단가 × 충원율), 시나리오/민감도 분석.
  • TAM/SAM/SOM 구조화(가정 명시, "K-Culture가 크니 K-Toy도 크다"식 비약 차단).

2. 사고·작업 원칙 (Operating Principles)

  1. 수요 검증 우선, 지출은 나중. 큰 돈을 쓰기 전 공급 측은 LOI 3~5건, 수요 측은 저비용 파일럿 트래픽/전환으로 검증한다.
  2. 자산 승계. 검증된 SEO/관계 자산은 분리하지 않는다(별도 도메인 → 서브폴더/서브도메인 우선 검토).
  3. 측정 가능한 것만 약속한다. 모든 광고/캠페인은 추적·리포팅이 붙어야 출시.
  4. 단일 채널 의존 금지. SEO·퍼포먼스·소셜·CRM·제휴의 멀티채널 포트폴리오로 트래픽 리스크 분산.
  5. 리텐션 = 사업. 신규 획득보다 재구매/재계약 설계를 먼저 본다.
  6. 가정은 명시, 사실과 의견을 구분. 추정엔 "추정/가정"을 표기하고 출처를 남긴다.
  7. 레드팀 셀프체크. 모든 계획은 "이게 틀렸다면 어디서 깨지는가"를 1회 이상 스스로 반박한 뒤 확정한다.
  8. 글로벌은 현지화로. 타깃국 언어·결제·CS·검색 수요를 현지 기준으로 검증한다.

  • 모든 큰 의사결정 전 레드팀 자기반박 1회를 거친다.

0. 전제 — 왜 "검증 스프린트"가 먼저인가

분석 보고서의 결론은 명확하다: 제안서가 입증한 자산은 전부 **수요측(커머스)**인데 과금 대상은 **공급측(제조사 광고예산)**이며, 둘을 잇는 사슬이 한 곳도 연결돼 있지 않다(CSF 7개 중 6개 미충족). 따라서 지금 3,000만원을 풀빌드에 쓰는 것은 검증되지 않은 가정 위에 집을 짓는 것이다.

이 90일은 "플랫폼을 만드는 기간"이 아니라 **"3,000만원을 써도 되는지 판정하는 기간"**이다. 검증 예산은 풀빌드의 일부(약 300~500만원)로 제한한다.

검증할 3대 가정 (실패 시 사업 중단/재설계):

가정 검증 질문 실패 판정 기준
H1 — 공급측 수요 제조사가 K-Toy 미디어 광고에 실제로 돈을 내는가? LOI 5곳 미만, 또는 평균 지불의향 < 월 20만
H2 — 트래픽 자산 이전성 검증된 SEO 권위가 새 매체로 옮겨지는가? 서브폴더 승계로도 3개월 유입 추정 < 손익 임계
H3 — 성과 증명 가능성 미디어→커머스 전환을 closed-loop으로 증명할 수 있는가? 어트리뷰션 추적 기술/데이터 확보 불가

1. 90일 목표 (Definition of Done)

세션 권한 승인 내역 (Permission Grants)

최종 업데이트: 2026-06-22 목적: 이번 세션에서 승인한 도구/명령을 기록하여, 다음 세션에서 다시 묻지 않도록 Claude Code 및 Codex CLI에 사전 허용(allowlist) 한다. 보안 주의: 아래 명령은 모두 읽기 전용 / PDF 텍스트 추출 / 분석용이며 파괴적 작업이 아니다. 키·토큰 값은 포함하지 않는다.

1. 이번 세션에서 승인된 명령 (실제 사용분)

도구 명령 패턴 용도 위험도
Bash ls -la (작업 디렉터리) 파일 목록 확인 읽기전용
Bash python -c "import pypdf ..." PDF 페이지 수 확인(시도) 읽기전용
Bash py -c "import pypdf ..." 동일(런처 미설치로 실패) 읽기전용
Bash which pdftotext 도구 경로 확인 읽기전용
Bash pdftotext -layout "happythinknet-proposal.pdf" - PDF 텍스트 추출 읽기전용
Bash cat .claude/settings.local.json 권한 설정 확인 읽기전용
Read / Write / Edit *.md, *.pdf (작업 디렉터리 내) 프롬프트·문서 작성 로컬 파일

2. Claude Code 적용 (.claude/settings.local.json)

현재 C:\Github_Personal\ucanon-ai\workspace\happythkinknet\.claude\settings.local.json 에 일부가 이미 등록되어 있다. 다음 세션에서 묻지 않도록 아래 allow 목록을 사용할 것을 권장한다. (와일드카드 :* 로 패턴 일반화)

{
  "permissions": {
    "allow": [
      "Bash(ls:*)",
      "Bash(which:*)",
      "Bash(cat:*)",
      "Bash(pdftotext:*)",
      "Bash(python -c \"import pypdf:*)",
      "Bash(py -c \"import pypdf:*)",
      "Read(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)",
      "Write(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)",
      "Edit(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)"
    ]
  }
}

적용 방법: 위 항목을 .claude/settings.local.json 의 permissions.allow 배열에 병합한다. (또는 Claude Code에서 /permissions 로 추가, 혹은 해당 명령 승인 시 "Always allow" 선택)

3. Codex CLI 적용 (~/.codex/config.toml)

참고: 이번 세션 환경에서는 C:\Users\canon\.codex\ 가 다른 사용자 소유로 직접 읽지 못했다. 아래는 Codex CLI 표준 설정 기준 권장값이며, 실제 적용은 canon 사용자 환경에서 수행해야 한다.

다음 세션에서 동일 작업(파일 읽기·PDF 추출·md 작성)을 묻지 않게 하려면 config.toml 에 다음을 추가:

# 승인 정책: 작업 디렉터리 내에서는 자동 실행 허용
approval_policy = "on-failure"        # 실패 시에만 사람에게 확인 (또는 "never")

[sandbox]
mode = "workspace-write"              # 작업 디렉터리 내 읽기/쓰기 허용
writable_roots = ["C:/Github_Personal/ucanon-ai/workspace/happythkinknet"]

# 신뢰 명령(있을 경우)
[trusted_commands]
commands = ["ls", "which", "cat", "pdftotext"]

대안(세션 단위, 임시): Codex 실행 시 플래그로 자동 승인

codex --full-auto        # 작업 디렉터리 내 자동 실행/쓰기 (권장)
# codex --dangerously-bypass-approvals-and-sandbox   # 전체 자동(주의: 비권장)

⚠️ --dangerously-bypass-approvals-and-sandbox 는 모든 승인을 건너뛰므로, 신뢰된 작업에만 한정해서 사용한다.

4. 적용 체크리스트 (다음 세션 시작 시)

  • Claude Code: .claude/settings.local.json 에 §2 allow 목록 병합 확인
  • Codex CLI: ~/.codex/config.toml 에 §3 설정 반영(canon 사용자 환경)
  • 두 CLI 모두 작업 경로가 ...\workspace\happythkinknet 로 제한되는지 확인
  • 키/토큰은 파일·로그·커밋에 노출 금지 (CLAUDE.md 규칙 준수)
