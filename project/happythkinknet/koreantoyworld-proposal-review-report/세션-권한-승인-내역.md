# 세션 권한 승인 내역 (Permission Grants)

> 최종 업데이트: 2026-06-22
> 목적: 이번 세션에서 승인한 도구/명령을 기록하여, **다음 세션에서 다시 묻지 않도록** Claude Code 및 Codex CLI에 사전 허용(allowlist) 한다.
> 보안 주의: 아래 명령은 모두 **읽기 전용 / PDF 텍스트 추출 / 분석용**이며 파괴적 작업이 아니다. 키·토큰 값은 포함하지 않는다.

---

## 1. 이번 세션에서 승인된 명령 (실제 사용분)

| 도구 | 명령 패턴 | 용도 | 위험도 |
|---|---|---|---|
| Bash | `ls -la` (작업 디렉터리) | 파일 목록 확인 | 읽기전용 |
| Bash | `python -c "import pypdf ..."` | PDF 페이지 수 확인(시도) | 읽기전용 |
| Bash | `py -c "import pypdf ..."` | 동일(런처 미설치로 실패) | 읽기전용 |
| Bash | `which pdftotext` | 도구 경로 확인 | 읽기전용 |
| Bash | `pdftotext -layout "happythinknet-proposal.pdf" -` | PDF 텍스트 추출 | 읽기전용 |
| Bash | `cat .claude/settings.local.json` | 권한 설정 확인 | 읽기전용 |
| Read / Write / Edit | `*.md`, `*.pdf` (작업 디렉터리 내) | 프롬프트·문서 작성 | 로컬 파일 |

## 2. Claude Code 적용 (`.claude/settings.local.json`)

현재 `C:\Github_Personal\ucanon-ai\workspace\happythkinknet\.claude\settings.local.json` 에 일부가 이미 등록되어 있다.
다음 세션에서 묻지 않도록 아래 `allow` 목록을 사용할 것을 권장한다. (와일드카드 `:*` 로 패턴 일반화)

```json
{
  "permissions": {
    "allow": [
      "Bash(ls:*)",
      "Bash(which:*)",
      "Bash(cat:*)",
      "Bash(pdftotext:*)",
      "Bash(python -c \"import pypdf:*)",
      "Bash(py -c \"import pypdf:*)",
      "Read(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)",
      "Write(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)",
      "Edit(//C/Github_Personal/ucanon-ai/workspace/happythkinknet/**)"
    ]
  }
}
```

> 적용 방법: 위 항목을 `.claude/settings.local.json` 의 `permissions.allow` 배열에 병합한다.
> (또는 Claude Code에서 `/permissions` 로 추가, 혹은 해당 명령 승인 시 "Always allow" 선택)

## 3. Codex CLI 적용 (`~/.codex/config.toml`)

> 참고: 이번 세션 환경에서는 `C:\Users\canon\.codex\` 가 다른 사용자 소유로 직접 읽지 못했다. 아래는 Codex CLI 표준 설정 기준 권장값이며, 실제 적용은 `canon` 사용자 환경에서 수행해야 한다.

다음 세션에서 동일 작업(파일 읽기·PDF 추출·md 작성)을 묻지 않게 하려면 `config.toml` 에 다음을 추가:

```toml
# 승인 정책: 작업 디렉터리 내에서는 자동 실행 허용
approval_policy = "on-failure"        # 실패 시에만 사람에게 확인 (또는 "never")

[sandbox]
mode = "workspace-write"              # 작업 디렉터리 내 읽기/쓰기 허용
writable_roots = ["C:/Github_Personal/ucanon-ai/workspace/happythkinknet"]

# 신뢰 명령(있을 경우)
[trusted_commands]
commands = ["ls", "which", "cat", "pdftotext"]
```

대안(세션 단위, 임시): Codex 실행 시 플래그로 자동 승인
```
codex --full-auto        # 작업 디렉터리 내 자동 실행/쓰기 (권장)
# codex --dangerously-bypass-approvals-and-sandbox   # 전체 자동(주의: 비권장)
```

> ⚠️ `--dangerously-bypass-approvals-and-sandbox` 는 모든 승인을 건너뛰므로, 신뢰된 작업에만 한정해서 사용한다.
